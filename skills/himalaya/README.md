# himalaya

로컬 [Himalaya CLI](https://github.com/pimalaya/himalaya)로 메일을 다루는 스킬입니다.
이미 설정된 계정과 인증을 사용해 메일 검색 · 열람, 첨부 다운로드, 초안 · 답장 · 전달,
발송과 메일함 정리를 수행합니다. 계정과 메일함은 실행 시 조회하므로 특정 사용자나 메일 제공자에 묶이지 않습니다.

## 필요한 것

- 에이전트가 실행할 수 있는 `himalaya` 바이너리와 설정된 메일 계정.
- 발송에는 해당 계정에서 사용하는 발송 백엔드 설정이 필요합니다. IMAP만 설정되어 있다고 발송까지 되는 것은 아닙니다.
- 예제는 **Himalaya v2.2.1**에서 검증했습니다. 다른 버전은 설치된 CLI의 `--help`에 맞춰 명령을 조정합니다. v1과 v2는 명령 · 옵션 · 출력 형식이 다릅니다.
- 명령 예시는 POSIX 셸 기준입니다. PowerShell에서는 바이너리 탐색, 변수와 파일 리디렉션 문법을 맞춰 사용합니다.

Himalaya 설치와 계정 설정은 [공식 안내](https://github.com/pimalaya/himalaya#configuration)를 따르세요.
스킬 설치는 [저장소 안내](../../README.md#설치)를 참고하세요. 이 스킬에는 계정 설정이나 인증 정보가 포함되지 않습니다.

## 쓰는 법

```text
히말라야로 기본 계정의 최근 안 읽은 메일을 요약해 줘.
Himalaya로 지정한 계정에서 주간 보고 메일을 찾아 첨부를 저장해 줘.
이 메일에 답장 초안을 만들어 줘. 발송은 하지 마.
```

계정을 지정하지 않으면 설정의 기본 계정을 사용합니다. 전체 계정을 원하면 요청에 명시하세요.
검색 범위는 계정 · 메일함별이며, 첫 페이지만 본 결과를 전체 검색 결과로 취급하지 않습니다.

초안 작성은 기본적으로 발송이나 서버 저장을 하지 않습니다. 서버 임시보관함 저장, 발송,
읽음 표시, 이동 · 삭제는 요청된 범위에서 수행합니다. 기존 메일함 이름이나 메시지 ID를 추측하지 않으며,
발송 결과가 불명확하면 자동 재발송하지 않습니다.

## 들어 있는 것

```text
SKILL.md                           계정 선택, 검색 · 열람, 첨부, 인증 · 오류 처리
references/writing-and-changes.md   초안 · 답장 · 발송과 메일 상태 변경
agents/openai.yaml                 Codex 표시 정보
```

## 검증 범위

v2.2.1의 임시 로컬 Maildir에서 한글 제목 · 본문과 첨부를 포함한 초안 작성, 검색,
읽음 상태를 유지하는 열람, 첨부 다운로드, 답장 스레드 헤더, 초안 저장 문법을 확인했습니다.
외부 메일 서버의 인증과 실제 발송은 이 검증에 포함되지 않습니다.
